# Trivia Universe

Trivia Universe lets players test their knowledge across 13 trivia categories:
Science, History, Movies, General Knowledge, Books, Music, Television, Video
Games, Computers, Mythology, Sports, Geography, and Animals.

Each category loads multiple-choice questions from the Open Trivia Database.
Players select an answer, receive feedback, and track their score for the
current visit. Ultimate Trivia serves questions from all 13 categories in a
shuffled sequence, showing every category once before reshuffling.

Each category card uses a bundled image from Unsplash, so the artwork does
not require a third-party image request at runtime. The images are used under
the [Unsplash License](https://unsplash.com/license).
